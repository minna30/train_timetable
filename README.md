# 背景
近年、乗換案内アプリ、鉄道会社が提供する運航アプリで、駅の時刻表を確認することができる。
他方で、特に乗換案内はベストな乗換方法を提案する他方で、乗りなれた経路であれば必要な情報はある駅をHH:MMに発車するのかという情報があれば十分である。
これは列車種別毎にどの駅に止まるのかをすべて把握しているからである。

鉄道会社が運行するアプリであれば上記の情報を入手することができるが、軽量でなく読み込みに時間を要すことがある。

そこで、特定の駅の発車時刻表を真似た軽量アプリを作成することで、次に何時何分の電車が来るのか一目で確認できることを目指す。

# 機能
- 駅レベルで複数の乗入路線の時刻表を同時に閲覧することができる。


# cheat_sheet

## 時刻をHH:MMに変換
検索欄：\b(\d{1,2}):(\d)\b
置換欄：$1:0$2

## ダブルクオーテーションで囲む
検索欄：^(\S+)\s+(\S+)\s+(.+)$
置換欄："$1","$2","$3"

## 既定のフォーマットに変換
検索欄：^"([^"]*)","([^"]*)","([^"]*)","([^"]*)","([^"]*)"
置換欄：{"line": "$1", "direction": "$2", "time": "$3", "train": "$4", "destination": "$5"},
